# Japanese Grammar Reference

A self-contained, offline-friendly study tool built from personal Japanese lesson notes (lessons 14–30). Single HTML file — no build step, no dependencies.

**Tabs:** Use Cases · Lesson · Conjugation · Vocabulary (flashcards) · Quiz

## View it live

Once this repo is published with GitHub Pages (see below), it will be available at:

`https://<your-username>.github.io/<repo-name>/`

## Publish with GitHub Pages

1. Create a new GitHub repository and upload `index.html` and `.nojekyll` to the root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Choose branch `main`, folder `/ (root)`, then **Save**.
5. Wait a minute for the first deploy, then open the URL GitHub shows you — it works on mobile and desktop.

## Local use

You can also just double-click `index.html` to open it directly in any browser, no internet or hosting required.
